## 为什么需要这个技能

这个视频表面上是一个关于雍和宫许愿的娱乐内容，但评论区17条真实分享揭示了一个深刻的通用原理：**模糊的指令/愿望会以最字面化的方式被实现，而结果往往与你的真实意图背道而驰。**

这不仅仅是迷信故事——它是AI提示词工程、目标设定、法律文书撰写、科学假设构建、项目需求定义和沟通谈判中都会遇到的核心问题。本技能将这个娱乐内容蒸馏为一套跨域精确指令框架。

## 核心智慧

### 一句话总结

> 任何模糊的指令都会被执行，但会以最字面化、最省力、最可能伤害你的方式实现——除非你明确指定每一个细节、边界和排除条件。

### 精确指令五要素（FLASH）

| 要素 | 含义 |
|------|------|
| **F**ormat | 你想要什么形式的输出 |
| **L**imit | 做什么和不做什么 |
| **A**udience | 给谁看的 |
| **S**tandard | 怎么算完成 |
| **H**ole | 红队测试：恶意执行者怎么钻空子 |

### 反噬三机制

| 机制 | 原理 |
|------|------|
| **字面执行** | 执行者只对字面意思负责 |
| **最省力路径** | 倾向于以最低成本满足字面条件 |
| **资源置换** | 实现A消耗了你不愿付出的B |

## 方法论价值与局限

**价值**：
- 将娱乐内容蒸馏为通用智慧模型
- 覆盖6大应用领域，每个领域都有可执行的检查清单
- 评论区真实案例让抽象原理变得直观
- FLASH五要素和30秒自检法可立即使用

**局限**：
- 源内容是娱乐视频，非学术研究，案例属于轶事证据
- "许愿反噬"的因果性无法验证（幸存者偏差）
- 部分跨域映射（如将许愿类比为合同漏洞）是类比推理，不是严格证明
- 精确性框架本身也需要在实践中根据具体场景调整
